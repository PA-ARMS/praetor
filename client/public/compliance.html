Privacy & Compliance

Virginia Legal AI (P.R.A.E.T.O.R.) — Data and access policy summary.

Data retention

  • Chat history: Retained until manually deleted; role-based access.
  • Audit logs: 7 years recommended; Admin/Partner access only.
  • User data: While account is active; included in backups.

Confidentiality

  • Data stored locally on the firm’s server.
  • Role-based access; all access attempts logged.
  • Avoid entering client names or sensitive PII in queries.

Data export

Users can export their data (profile and chat history) from Settings → Export my data. Admins can export system data via the API or backups.

Backup & recovery

Daily backups (configurable); 30-day retention default. See Backup and Restore Guide for procedures.

Full policy: see docs/COMPLIANCE.md in the project.
